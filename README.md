# VK Base

Автономная статическая база знаний о ВКонтакте. Не зависит от основного приложения iiai.pro.

## Развёртывание

1. Разместить содержимое каталога на сервере в `/srv/vkbase/current/`.
2. Добавить только route из `nginx-vkbase.conf` в reverse proxy домена `iiai.pro`.
3. `nginx -t && systemctl reload nginx`.
4. Адрес: `https://iiai.pro/vkbase/`.

## Обновление данных

Главный реестр разбит на `data/features-*.json`, список частей — `data/manifest.json`. UI собирает их автоматически: категории, поиск, фильтры, счётчики и карточки.

Рекомендуемый ежедневный pipeline:
- собрать изменения из официальной документации, GitHub VKCOM, changelog/release notes и надёжных публичных наблюдений;
- подтверждённые записи обновлять/добавлять в feature-файлы;
- добавлять краткую запись в `changes` в `data/manifest.json`;
- менять `meta.lastVerified`;
- деплоить только этот каталог независимо от iiai.pro.

## Статусы
- `verified` — подтверждено актуальным официальным источником;
- `rollout` — работает частично, есть platform/version caveats или открытая проблема;
- `rare` — малоизвестная публичная возможность, найденная в актуальном SDK/исходниках;
- `legacy` — историческая/устаревающая возможность, требующая ручной проверки.
